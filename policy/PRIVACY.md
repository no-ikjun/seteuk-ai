# 개인정보 처리 안내

세특척척은 학생 활동 기록을 바탕으로 세특 초안을 생성하기 위해 OpenAI API를 사용합니다.

## 앱에 저장되는 정보

- 업로드한 원본 파일은 앱 전용 저장소에 저장하지 않습니다.
- 학생 활동 기록과 생성 결과는 앱 실행 중 메모리에만 유지됩니다.
- OpenAI API Key는 파일이나 설정에 저장하지 않으며 앱을 종료하면 폐기됩니다.
- 사용자가 직접 내보낸 결과 파일은 사용자가 선택한 위치에 저장됩니다.

## OpenAI로 전송되는 정보

세특 생성 시 다음 정보가 OpenAI API로 전송됩니다.

- 과목과 주제
- 목표 분량과 작성 형식
- 문체 참고용 예시 글
- 사용자가 선택한 활동 컬럼의 이름과 내용
- 교사가 입력한 추가 키워드

원본 엑셀 파일 전체와 생성 결과 파일 자체는 OpenAI로 전송하지 않습니다.

앱은 최초 생성 전에 외부 전송 사실을 확인하고, 화면에 학생별 최종 활동 텍스트를 미리 표시합니다. OpenAI Responses API 요청에는 `store: false`를 명시해 응답 저장 기능을 비활성화합니다. 다만 OpenAI의 보안·오남용 모니터링과 API 계정별 데이터 처리 정책까지 앱이 통제하는 것은 아닙니다.

## 학생 식별정보

앱은 이름, 성명, 학생명, 학번, 번호, ID 등으로 추정되는 컬럼을 기본 활동 컬럼에서 제외합니다. 다만 사용자가 해당 컬럼을 직접 활동 컬럼으로 선택하면 그 내용이 OpenAI로 전송될 수 있습니다.

생성 전에 화면의 활동 기록 미리보기를 확인하고 학생 이름, 학번 등 불필요한 식별정보를 제외해야 합니다.

## 외부 서비스

OpenAI로 전송된 데이터에는 사용 중인 API 계정과 OpenAI의 데이터 처리 정책이 적용됩니다. 학교 또는 기관의 개인정보 처리 기준과 OpenAI API 이용 조건을 확인한 뒤 사용해야 합니다. 앱은 요청 본문이나 생성 결과를 자체 서버에 수집하지 않습니다.

## 사용자 책임

생성된 내용은 AI가 작성한 초안입니다. 교사가 사실관계, 개인정보 포함 여부와 표현의 적절성을 검토한 뒤 사용해야 합니다.
